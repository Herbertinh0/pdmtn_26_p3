# Cat App

Aplicativo desenvolvido em React Native (Expo) que exibe fotos de gatos
obtidas através da [TheCatAPI](https://developers.thecatapi.com/).

## Integrantes

- Herbert Fagundes S. Carvalho 

## Funcionalidades

- A cada clique no botão "Carregar 5 fotos", a aplicação busca e exibe
  5 novas fotos de gatos.
- As fotos são exibidas empilhadas verticalmente, em uma tela com
  rolagem (scroll) vertical.

## Tecnologias

- React Native
- Expo
- Axios
- TheCatAPI
